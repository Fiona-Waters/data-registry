# Authorization

Having a valid RHOAI/OpenShift token does not guarantee access to every Data Registry project or operation. Authorization is determined by the permissions configured in the RHOAI environment.

This page will document the supported roles, the project scope at which they apply, and how a user or administrator can check access. Role names, exact permissions, and verification commands must be confirmed against a supported product release before being published as instructions.

If a request is denied, confirm that you selected the intended project and ask your RHOAI administrator to verify your access. Do not assume that dashboard access and direct API access have identical permissions until the product behavior is documented for your release.
