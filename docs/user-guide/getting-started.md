# Getting started

This page will provide the shortest supported path for making a first Data Registry API request as a RHOAI user.

Data Registry records asset metadata; registering an asset does not upload its underlying data.

## Before you begin

You need:

- access to a RHOAI environment where the Data Registry API is available;
- the project (OpenShift namespace) whose registry you intend to use; and
- a RHOAI/OpenShift token accepted by that environment.

## Find the API endpoint

The supported API URL and the way to discover it must be documented for each supported deployment. Ask your cluster administrator or consult the product documentation for your installed RHOAI release. A verified discovery procedure and first-request example will be added here.
